# Garden City Property Care

Static website for Garden City Property Care in Richmond, British Columbia.

## Files

- `index.html` — main page
- `styles.css` — layout and design
- `script.js` — mobile menu and quote form
- `favicon.svg` — browser icon

## GitHub Pages

1. Upload all files to the repository root.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**.
5. Save.

## Custom domain

Use:

`gardencitypropertycare.com`

The site currently uses `info@gardencitypropertycare.com` in the contact section. Replace it in `index.html` and `script.js` if a different email address is preferred.
